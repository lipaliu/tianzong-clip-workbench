## 团队第一次试用步骤

1. 打开团队工作台并使用内部账号登录。
2. 点击“选择原片”，上传一条 MP4 或 MOV；首轮建议使用 10–30 分钟、无敏感内容的录屏。
3. 选择“聊播”或“带货”。
4. 首轮选择“**三模型对比**”，使 OpenAI、Kimi K3、豆包读取同一份私有 Skill。
5. 等待任务完成后，对候选逐条观看、保留/删除；不要把模型候选直接当作最终发布内容。
6. 查看候选页的成本台账，再导出 MP4、SRT 或 XML。
7. 记录每家模型的候选质量、人工采纳率、错误类型和实际费用，作为后续替换 API 的依据。
