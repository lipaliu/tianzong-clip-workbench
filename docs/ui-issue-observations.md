# 线上界面问题实测记录（2026-08-13）

线上地址：<https://tianzong-clip-workbench.lipaliu514.workers.dev/>

在 1560 宽度视口下实际截图观察到的问题：

1. **主标题过大且强制折行。** “今天要剪哪一场直播？”被压成两行超大字，占据首屏大量高度，与右侧小字说明形成极不协调的对比。
2. **步骤条与上传卡片被压成窄竖列，中文逐字竖排。** STEP 1 的“上传直播”、STEP 2 的“选择类型”、以及两张上传卡的标题（“上传整场直播，开始找天总切片”“上传 SRT，跳过自动转写”）都在极窄列内逐字换行，形成用户所说的“文字挤在一起”。
3. **主内容区被挤到中间窄栏。** 页面左右留有大片空白，主工作区宽度不足，右侧“天总专属模型”栏与主区之间比例失衡，横版空间没有被利用。
4. **辅助说明字号过小。** 大量 6px–9px 的字号（`font-size: 6px` / `8px` / `9px`）配合 0.12em–0.18em 字距，正文与标签几乎不可读。
5. **卡片内文本行宽过窄。** 上传卡说明文字每行仅容纳 6–8 个汉字，阅读被频繁打断。

修复目标：恢复常规可读字号层级（标签 12–13px、正文 14–15px、卡片标题 18–22px、页面主标题 30–36px 且不强制折行）、恢复横版三栏/两栏布局、上传卡片改为并排横向卡片且有足够行宽、去掉超小字号与过大字距。
